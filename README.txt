# Baustellenzeit – Prototyp v1

Eine einfache iPhone-optimierte Web-App (PWA) für:
- Arbeitszeit
- Material
- Werkzeug
- Baustellen
- Übersicht

Die Daten werden im Browser lokal gespeichert.

Für die Nutzung auf dem iPhone sollte die App über HTTPS bereitgestellt werden (z.B. GitHub Pages). Danach in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Hinweis: Dieser Prototyp ist die erste Version. PDF/Excel-Export, iCloud-Synchronisierung und weitere Komfortfunktionen können danach ergänzt werden.
